# RF circuit blocks

Amplifier, oscillator/VCO, PLL, mixer, multiplier, filter, diplexer/duplexer,
coupler/divider, isolator/circulator, antenna를 송수신 chain 안에서 봅니다.

각 block 앞뒤에 frequency, impedance, gain/loss, noise, linearity, termination을
기록합니다. FMCW radar에서는 PLL/VCO chirp와 mixer beat 이후의 ADC·FFT 처리를
별도 단계로 둡니다.
