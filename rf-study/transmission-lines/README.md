# Transmission lines

전기적 길이, 진행파·반사파, characteristic impedance에서 시작해 microstrip,
stripline, CPW, coax, waveguide를 return path와 mode 기준으로 비교합니다.

- `λ = vp/f`, `θ = βl`
- `Z0 = √(L′/C′)` for an ideal lossless line
- Microstrip closed-form 값은 stack-up별 초기값이며 EM·VNA 결과가 아닙니다.

내 3.5 GHz alumina 과제의 저장 치수는
[`04_rf_microwave`](../../04_rf_microwave/passive_network_design/cases/homework2_microstrip.md)에
분리해 두었습니다.
