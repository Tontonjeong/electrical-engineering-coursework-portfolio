Problem and design decisions

The source material traces a progression from logic equations through hierarchy, state machines, and register control. Because not every source file was recoverable, recovered originals and public reconstructions are separated in both the tree and the evidence labels.

  • Small combinational blocks use exhaustive input-space checks.
  • Sequential tests isolate reset, hold, load, both shift directions, and overlap detection.
  • Public reconstructions avoid non-standard arithmetic packages and use numeric_std.
  • Assertions fail CI, while successful runs emit PASS messages and VCD evidence.

Verification boundary

Four original Vivado 2023.2 projects and XSim contexts were recovered, but device constraints, implementation reports, and board evidence were not. Original benches contain no assertions and are labelled STIMULUS_COMPLETE; PASS belongs only to the separate self-checking GHDL 6.0.0 suite. FPGA utilization, Fmax, power, and hardware PASS are not claimed.
