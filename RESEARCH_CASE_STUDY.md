# Electrical Engineering Coursework — Research Case Study Guide

> Course source → engineering question → calculation/model → simulation or implementation → result → what to review next

**Coursework hub:** https://dororok9061.github.io/coursework/  
**Repository:** this repository

## Why this format

The portfolio spans control, power, electrical machines, RF/microwave, sensors, digital logic/FPGA, embedded systems, communications, circuits, and PCB design. Instead of presenting each assignment as a file list, each public page follows the same research-case structure so a reader can understand the engineering question, the method used, and the result or remaining task.

## Page Structure

1. **Overview** — what the unit or assignment is about.
2. **Concept Map** — four terms that connect the topic into one engineering flow.
3. **Technical Anchor** — equation, circuit relation, algorithm, model, or design constraint used for the topic.
4. **Method / Review Sequence** — how the calculation, simulation, code, or tool output is checked.
5. **Result / Course Context** — what the saved result shows and how the unit connects to the rest of the course.
6. **Figures** — source screenshots, plots, circuit diagrams, waveform captures, or a source-faithful redraw when the original visual cannot be published directly.

## Figure Rule

If a saved source figure exists, the public page uses that figure or a privacy-safe crop. If no publishable source figure exists, the website generates a concept/flow diagram from the structured course data. Higher-fidelity academic redraws are tracked through the PaperBanana figure manifest in the main portfolio repository; generated visuals must not invent measurements, component values, or results.

## Main Portfolio

The Jekyll portfolio applies this structure automatically to the individual coursework-unit pages, so the repository source files and the public study pages remain connected without replacing the existing site theme.
